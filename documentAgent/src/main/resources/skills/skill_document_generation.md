# 文档生成技能

此技能能够根据用户提供的主题、类型和上下文，生成高质量的结构化文档。

## 使用场景
- 技术报告生成：输入技术主题和要点，输出格式化技术报告。
- 市场分析报告：输入市场数据和分析维度，输出专业分析报告。
- 会议纪要：根据讨论要点生成结构化的会议纪要。

## 参数说明
- `topic`: 文档主题（必填）
- `docType`: 文档类型，如 `report`、`summary`、`manual`、`meeting_minutes`
- `style`: 风格偏好，如 `formal`、`technical`、`casual`
- `length`: 期望篇幅，如 `short`、`medium`、`detailed`

## 输出格式
- 默认输出 Markdown 格式，支持标题、列表、表格等
- 可通过配置输出纯文本或结构化 JSON

## 协作能力
- 支持多轮对话迭代优化，根据用户反馈修改文档
- 可调用其他 Agent（如数据分析 Agent）获取辅助数据
- 可结合用户画像自动调整文档风格和深度

## 示例
- 用户：生成一份关于 Spring AI 的技术报告
- 输出：包含概述、核心功能、示例代码、总结等部分的 Markdown 文档
