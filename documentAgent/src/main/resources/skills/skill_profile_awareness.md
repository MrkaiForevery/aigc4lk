# 用户画像感知技能

此技能能够根据用户的历史行为、偏好设置和交互数据，自动调整文档生成的风格、深度和语气。

## 核心能力
- 读取用户画像数据（技术等级、沟通风格、偏好语言等）
- 读取用户偏好设置（输出风格、详细程度、敏感信息偏好等）
- 根据画像动态调整生成内容的语气和复杂度

## 适用场景
- 为初级用户生成通俗易懂的说明文档
- 为高级用户生成技术深度较高的专业报告
- 根据用户偏好自动选择正式/随意的沟通风格

## 参数说明
- `userId`: 用户标识（必填）
- `profileAspect`: 画像维度，如 `technical_level`、`communication_style`、`language_preference`
- `fallbackDefaults`: 当画像缺失时使用的默认值，如 `{"technical_level": "intermediate", "style": "professional"}`

## 行为准则
- 画像数据获取失败时，必须使用默认值，不能中断流程
- 画像信息仅用于调整生成策略，不得泄露或传递给第三方
- 对于敏感属性（如健康、财务），除非用户明确授权，否则不应使用

## 示例
- 用户画像：技术等级=高级，偏好风格=极简
- 生成文档：使用专业术语，省略基础解释，直接给出关键结论
